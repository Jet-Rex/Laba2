# Лабораторная работа: Циклы с пред- и постусловием

## Автор
Базанов Влад (Вариант 1)

## Цель
Освоение циклав с пред- и постусловием в C++.

## Описание
Программа вычисляет период колебаний математического маятника по трем формулам разной точности.

## Исходные данные
- Масса: 75 кг
- Коэффициент сопротивления: 8 кг/м
- Ускорение свободного падения: 9.8 м/с²

## Ожидаемые результаты
Программа выводит значения времени и скорости
